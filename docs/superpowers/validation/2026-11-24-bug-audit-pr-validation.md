# Bug 审计台账 PR 验收范围

## 交付内容

- Bug 审计专属运行、候选、字段和事件表；阶段化 CLI；权限保护的只读 API；每日审计运行页面。
- 北京时间窗口与毫秒精度、真实变更筛选、联合 History 去重、事件幂等、逐字段 ready/冲突/回读状态、pending 整单状态与恢复。
- 合成 JSON、历史样本路径模板、部署使用说明。没有独立 Worker 或外部副作用执行器。

## 可重复验证

在项目根目录、Python 3.11+ 环境中执行：

```powershell
python -X utf8 -m unittest discover -s tests -v
node --check outputs/SQA_MVP/web/app.js
git -c core.whitespace=cr-at-eol diff --check
```

专属测试使用临时数据库与合成输入，覆盖 CLI 完整链路及重复回放、只读 API 权限、字段状态恢复、时间精度、多选比较以及缺少可选时区数据时的启动兼容。CLI 子进程写入的完整成功运行能够经 HTTP API 查询，失败事务不会留下伪成功事件。

PR 准备阶段在 Python 3.13 上完成 32/32 测试；另外从 Git 暂存区导出干净快照，脱离本机 work 目录再次运行同一完整测试集，32/32 通过。JavaScript 语法和差异空白检查通过。

已在真实浏览器中检查合成样例的快照空状态、每日运行列表、详情、History、三个字段结果、附件不匹配提示和重复视图切换；桌面与窄屏无整页横向溢出，表格在专属容器内滚动。页面无 warning/error 日志。
